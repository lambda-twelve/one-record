# NE:ONE interoperability

[NE:ONE](https://ne-one.de/) is the Open Logistics Foundation's ONE Record
server (Java). The interoperability suite publishes the same graph to NE:ONE
and to this package's server, reads both back and compares them as RDF graphs,
and also drives this package's client against NE:ONE.

*Results are recorded here as the suite lands (roadmap phase 8).* Every
difference is either a fix here or an entry in
[Open specification questions](../spec-questions.md).
